OWASP API Security Top 10 — Attack Demonstrations
API1:2023 CVSS 8.1 HIGH
Broken Object Level Auth (BOLA / IDOR)
User1 enumerates all 15 user profiles by guessing sequential integer IDs. In vulnerable mode: password hashes, admin flags, and UUIDs are all exposed.
API3:2023 CVSS 7.5 HIGH
Mass Assignment — Privilege Escalation
Registers a new user then sends is_admin: true in the update payload. In vulnerable mode: the API blindly assigns any field sent.
API3:2023 CVSS 7.5 HIGH
Excessive Data Exposure
Audits what sensitive fields each endpoint returns. In vulnerable mode: password hashes, internal UUIDs, cost prices, and admin flags leak in every response.
API2:2023 CVSS 9.8 CRITICAL
Broken Authentication — JWT Attacks
Fires three attacks: none-algorithm (strip signature), expired token (no expiry check), and role tamper (wrong secret). Vulnerable mode accepts forged tokens.
API4:2023 CVSS 7.5 HIGH
Unrestricted Resource Consumption — Brute Force Login
Fires 10 rapid POST /auth/login requests with wrong passwords. In vulnerable mode: all 10 return 401 with no throttling. In secured mode: rate limiter triggers 429 after 5 attempts with Retry-After header.
